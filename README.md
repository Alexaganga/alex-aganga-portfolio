> Personal engineering portfolio of **Alex Aganga Nyokwoyo** — Full-Stack, Mobile & DevOps Software Engineer based in Nairobi, Kenya. Built with Next.js 16 (App Router), React 19, Tailwind CSS v4, and Framer Motion with a Cyber-HUD design aesthetic.

🌐 **Live Website**: [https://alex-aganga-portfolio.vercel.app](https://alex-aganga-portfolio.vercel.app)

---

## ⚡ Core Features

- **Cyber HUD Design System**: Custom neon HUD accents, interactive holographic globe, 3D rotating geometry, and smooth responsive animations via Framer Motion.
- **Production Projects Showcase**: Live screenshot previews and explicit technology stacks for 7 production platforms (Nairobi Feast, Agropests, Crypto Compass, LinuxLeap, Ebook Corner, MacAgutu Hotel, Kool Afrika).
- **Career Trajectory & Experience**: Detailed breakdown of 6+ years in production engineering (Elimn, CoffeeBee Processors, Samsoft Technologies, Sendy Ltd, Zumi Africa).
- **Education & Certifications**: Academic foundations from JKUAT paired with certifications across AWS Cloud, AI/ML, and Mobile Architecture.
- **Curriculum Vitae Integration**: Direct download and in-browser access to updated CV (`/Alex_Aganga_CV.pdf`).
- **SEO & Social Optimization**: Open Graph 1200x630 preview card, Twitter summary card, JSON-LD Schema.org structured data, and security headers.

## 🚀 Getting Started

### Prerequisites

- Node.js >= 20.9.0
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/Alexaganga/alex-aganga-portfolio.git
cd alex-aganga-portfolio
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Typecheck

```bash
# Typecheck
npm run typecheck

# Lint
npm run lint

# Production build
npm run build
```
